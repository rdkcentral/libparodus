# libparodus

C implementation of the Parodus adapter

[![Apache V2 License](http://img.shields.io/badge/license-Apache%20V2-blue.svg)](LICENSE)
[![GitHub release](https://img.shields.io/github/release/rdkcentral/libparodus.svg)](https://github.com/rdkcentral/libparodus/releases)

# Building and Testing Instructions

```
mkdir build
cd build
cmake ..
make
make test
```

## Origin

This repository is based on the original
[libparodus](https://github.com/xmidt-org/libparodus) source code
maintained under the xmidt-org organization. The code was copied into the
rdkcentral organization, where ongoing maintenance and development now take place.

- Original project: https://github.com/xmidt-org/libparodus
- Current repository: https://github.com/rdkcentral/libparodus
